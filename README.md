# C++ Modules @ 42 Porto

## Overview

This repository contains my solutions for the **C++ Modules** project from the **42 Porto** curriculum. The project consists of ten modules (CPP00–CPP09), each introducing new C++ concepts through practical exercises that increase in complexity.

The curriculum starts with the foundations of object-oriented programming and gradually explores more advanced language features, including inheritance, polymorphism, templates, exception handling, and the Standard Template Library (STL). By the end of the project, the focus shifts to solving real-world programming problems using efficient data structures and algorithms.

---

## Learning Goals

Throughout these modules, I learned to:

- Design software using object-oriented programming principles.
- Understand object lifetime, constructors, destructors, and resource management.
- Apply inheritance, polymorphism, and abstract classes to create extensible code.
- Handle runtime errors using exceptions.
- Write generic code with templates.
- Work effectively with STL containers, iterators, and algorithms.
- Develop clean, reusable, and maintainable C++ code while following the C++98 standard.

## Modules

| Module | Main Topics |
| :----: | ----------- |
| **CPP00** | Classes, member functions, namespaces, streams, static members |
| **CPP01** | Dynamic memory, references, pointers, object lifetime |
| **CPP02** | Canonical Orthodox Form, operator overloading |
| **CPP03** | Inheritance and class hierarchies |
| **CPP04** | Polymorphism, abstract classes, interfaces |
| **CPP05** | Exceptions and error handling |
| **CPP06** | Scalar type conversions and casts |
| **CPP07** | Function and class templates |
| **CPP08** | STL containers, iterators, algorithms |
| **CPP09** | Practical applications using STL and algorithm implementation |
